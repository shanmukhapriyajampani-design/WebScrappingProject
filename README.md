# Tech Job & Skill Analyzer

🔗 **Live Demo:** [job-analyzer-in-tech.onrender.com](https://job-analyzer-in-tech.onrender.com)

## Overview
An interactive web application built to analyze tech job market trends and evaluate candidate resume compatibility against target job descriptions in real time.

## Key Features
* **Market-Wide Skill Insights:** Interactive visualizations displaying the top in-demand technical skills across leading product companies.
* **Resume & JD Matcher:** Evaluates candidate fit scores by extracting key skills from uploaded resumes and comparing them against target job descriptions using automated regex matching.
* **Multi-Format Support:** Parses candidate profiles in PDF, DOCX, and plain TXT formats.
* **Skill Gap Identification:** Highlights missing keywords to help candidates optimize their resumes for Applicant Tracking Systems (ATS).

## Tech Stack
* **Language & Analysis:** Python, Pandas, Regex (`re`)
* **Document Parsing:** `pypdf`, `python-docx`
* **Web Interface:** Streamlit, HTML/CSS
* **Deployment & DevOps:** Docker, Render (CI/CD), Git, GitHub
